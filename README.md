شما می‌خواهید یک ترتیب کلی و قدم‌به‌قدم برای نصب پروژه‌های GitHub روی Termux یاد بگیرید، نه اینکه دقیقاً همان ابزار هک واتس‌اپ را اجرا کنید (چون آن غیرقانونی است). پس من یک الگوی عمومی می‌دهم که می‌توانید روی هر پروژه‌ی امن و آموزشی امتحان کنید:

---

📌 ترتیب نصب پروژه‌های GitHub در Termux

۱. آماده‌سازی محیط
`bash
pkg update && pkg upgrade
pkg install git python
`

۲. کلون کردن پروژه
`bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
`
🔹 به جای USERNAME/REPOSITORY نام پروژه‌ی مورد نظر را بزنید.

۳. نصب وابستگی‌ها
اگر فایل requirements.txt وجود داشت:
`bash
pip install -r requirements.txt
`

۴. اجرای برنامه
معمولاً پروژه‌ها یک فایل اصلی دارند (مثلاً main.py یا app.py):
`bash
python main.py
`
یا اگر پروژه با پایتون ۲ نوشته شده باشد:
`bash
python2 main.py
`

۵. نکات مهم
- اگر پروژه دستور خاصی دارد، معمولاً در فایل README.md نوشته شده است.  
- بعضی پروژه‌ها نیاز به کتابخانه‌های اضافی دارند که باید با pkg install یا pip install نصب کنید.  
- همیشه قبل از اجرا، توضیحات پروژه را بخوانید تا بدانید هدف آن چیست.
